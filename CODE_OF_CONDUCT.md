# Code of Conduct

## Our commitment

We are committed to a welcoming, respectful, and harassment-free community for everyone, regardless of identity, background, experience, or viewpoint.

## Expected behavior

- Be respectful and constructive.
- Assume good faith while checking claims with evidence.
- Explain safety and compatibility concerns without attacking people.
- Protect private information in logs, reports, and examples.
- Welcome corrections, especially when a proposed change could terminate a process.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, doxxing, sexualized conduct, deliberate exposure of private data, and knowingly unsafe instructions are not acceptable.

## Enforcement

Report a concern privately to the project maintainers through the same private channel used for
security reports: the repository's GitHub page, **Security → Report a vulnerability** (a private
advisory). This project publishes no security email address and no maintainer handle, so that
form is the only private channel — do not open a public issue for a conduct concern. Include links
or a factual description, and avoid posting sensitive details in a public issue. Maintainers may
edit or remove harmful content, pause participation, or take other action needed to keep the
project safe.

This code follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
